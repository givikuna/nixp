# Security Policy

## Supported Versions

Nixp is currently in early development, as such, security fixes are only provided for the latest published version.

Past `v0.1.0` we will be providing them for all versions however.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

To report a vulnerability, report to one of the core maintainers as described in the `./maintainers/` folder `README.md` file.
Or simply to `gvtsvariani@gmail.com`

Please include (if possible):

- A description of the issue
- Potential impact of the vulnerability
- The affected version (see `.version`) or commit hash
- Any suggested mitigation or fix

## What to Report

- Injected code generation
- Unsafe handling of imported Nix code
- Supply chain attacks

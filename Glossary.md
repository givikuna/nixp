# Nixp Glossary

| Term         | Definition                                                                                                               | Further Reading                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CST          | Concrete Syntax Tree, produced by the parser do operations on the syntax tree before simplifying to an AST               | <a href="https://stackoverflow.com/questions/1888854/what-is-the-difference-between-an-abstract-syntax-tree-and-a-concrete-syntax-tre">Stack Overflow</a> |
| AST          | Abstract Syntax Tree, the syntax tree for describing nicely to the compiler what the given source code looks like        | <a href="https://en.wikipedia.org/wiki/Abstract_syntax_tree">Wikipedia</a>                                                                                |
| Type Erasure | Step performed by the AST parser, where it removes all the types from the language (after type checking has taken place) | <a href="https://en.wikipedia.org/wiki/Type_erasure">Wikipedia</a>                                                                                        |
| Unparser     | Turns an AST into source code text                                                                                       | <a href="https://en.wikipedia.org/wiki/Unparser">Wikipedia</a>                                                                                            |
